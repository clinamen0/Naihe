# NaiHe

*Да встретимся мы там, где есть свет.*

NaiHe — легковесный инструмент для сквозного шифрования связи. Создан, чтобы помочь обычным людям в странах с жёсткой цензурой общаться свободно и безопасно.

Это не просто зашифрованный мессенджер. Это инструмент для тех, кто живёт под наблюдением и цензурой — чьи сообщения отслеживаются, чьи аккаунты блокируются, чьи голоса заглушаются. NaiHe даёт им возможность говорить без страха.

Без аккаунтов. Без номеров телефонов. Без централизованных серверов. Только пароль и общий ключ.

## Возможности

### Защищённый чат (Secure Room)
Зашифрованный чат в реальном времени через любой MQTT-брокер. Два человека делятся именем комнаты и ключом шифрования; все сообщения шифруются на устройстве отправителя и расшифровываются на устройстве получателя. Сервер-ретранслятор видит только шифротекст.

### Шифроблокнот (Cipher Pad)
Режим шифрования через буфер обмена. Автоматически обнаруживает шифротекст в буфере обмена и расшифровывает его; введите обычный текст, чтобы зашифровать и автоматически скопировать в буфер.

## Сценарии использования

- **Журналисты**, общающиеся с источниками в регионах с цензурой
- **Активисты**, координирующие действия без централизованных платформ
- **Обычные люди**, желающие частных разговоров без государственного наблюдения
- **Информаторы**, безопасно передающие информацию
- **Любой** в регионе, где мессенджеры со сквозным шифрованием заблокированы

## Архитектура безопасности

| Компонент | Алгоритм |
|-----------|----------|
| Шифрование | ChaCha20-Poly1305 (IETF AEAD) |
| Деривация ключа | Argon2id (64 МБ, 3 итерации, 4 потока) |
| Хеширование топиков | SHA-256 (первые 8 hex-символов) |
| Локальная история | Файлы, зашифрованные ChaCha20-Poly1305 |

**Всё шифрование и дешифрование происходит на вашем устройстве. На сервере ничего не расшифровывается. Сервер — просто ретранслятор.**

## Границы безопасности

### Что NaiHe защищает:
- Перехват сообщений на сервере
- Пассивное сетевое наблюдение
- Подделку сообщений
- Перебор ключей

### Что NaiHe НЕ защищает:
- **Скомпрометированные устройства** — кейлоггеры и вредоносное ПО обходят любое шифрование
- **Анализ трафика** — наблюдатель может видеть факт подключения к MQTT-серверу
- **Обмен ключами** — вы должны передать ключ через отдельный безопасный канал
- **Метаданные** — временные метки, IP-адреса и размеры сообщений видны оператору сервера

### Потенциальные риски

> **ВНИМАНИЕ:** В некоторых юрисдикциях само использование средств шифрования может привлечь внимание. Оцените правовые и личные риски перед использованием.

- Данное ПО **не прошло профессиональный аудит безопасности**
- Автор анонимен и не будет предоставлять поддержку

## Кастомизация

Редактируйте `src-tauri/src/config.rs` для изменения пароля, параметров шифрования и пространства имён.

Для замены алгоритма шифрования перепишите `src-tauri/src/cipher.rs`, сохранив 7 функций-интерфейсов (`check_gate`, `seal`, `unseal`, `seal_bytes`, `unseal_bytes`, `resembles_cipher`, `room_topic`).

### Добавление языка

1. Скопируйте `ui/i18n/en.js` в новый файл
2. Переведите все строки
3. Импортируйте в `ui/i18n/index.js` и добавьте в объект `LANGUAGES`
